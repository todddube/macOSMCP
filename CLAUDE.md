# MacBridge

Swift menu-bar app + CLI serving macOS Calendar and Reminders to AI clients over MCP.
Project coding standards: `.claude/swift-standards.md` (layered on `~/.claude/swift-standards.md`).
The `swift-code-reviewer` agent (in `~/.claude/agents/`) runs after Swift changes; see the global CLAUDE.md.

The `~/.claude/` paths above are the maintainer's local Claude Code tooling; they are not
part of the project and contributors don't need them.
